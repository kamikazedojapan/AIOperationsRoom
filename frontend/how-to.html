GUIA

Como utilizar

Observe sessões externas no Escritório ou inicie uma tarefa explícita pela Agent Console.

VERSÃO NÃO TÉCNICA

Veja o trabalho acontecendo

O AI Operations Room organiza sessões de Claude Code, Codex e integrações OpenAI em uma visão única. Cada projeto aparece como uma sala e cada agente aparece trabalhando, aguardando ou concluindo uma tarefa.

Passos rápidos

  1. Abra a página Projetos e cadastre suas pastas locais.
  2. Use normalmente os provedores externos configurados para alimentar a telemetria metadata-only.
  3. Abra a Agent Console quando quiser iniciar uma task explicitamente pelo Operations Room.
  4. Acompanhe status, timeline e resposta final sem recarregar a página.

O Escritório atualiza automaticamente a cada 4 segundos e a Agent Console consulta progresso aproximadamente a cada segundo.

VERSÃO TÉCNICA

Observabilidade e Task Runner

Hooks/adapters normalizam fatos de cada provider para o contrato interno. A telemetria global continua sem prompt ou resposta. Já o conteúdo digitado diretamente na Agent Console pertence à própria task e é persistido separadamente nas tabelas task e task_event.

Configuração

  1. Instale/configure os hooks do provider conforme o README e a documentação em docs/.
  2. Mapeie as raízes dos repositórios em Projetos.
  3. Para OpenAI Agents API, configure OPENAI_API_KEY.
  4. Use a Agent Console para criar uma execução provider-neutral pelo backend.

O projeto selecionado na Agent Console é metadado local; ele não envia automaticamente a pasta local para um sandbox remoto.
